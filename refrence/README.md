# GENRANQ CMS v3

Open `genranq-cms-dashboard.html` in a browser, then log in with admin@genranq.com / admin123 (change it under Users & roles).

**Upgrading?** Open the new file in the same browser you used before. Your posts, leads, media and settings are kept. The sample pages are replaced with the new design versions, and your old versions are saved under each page's Revisions.

## What's new
- **Design sections (39).** Every section of the Home, AI SEO, Web Development and Hire Resource pages can be edited and renders exactly like the original HTML. Each section has Section settings: H1–H6/p/div tags for the title, item titles, intro and eyebrow (the look stays the same when you change a tag), background, spacing, width, image height/fit/radius, alignment, anchor ID, show/hide on mobile or desktop, and custom CSS.
- **Blog & News** use the final_blog and final_news designs. **Glossary, White papers (with gated PDF download) and Publications** have new designs in the same style, and each one has an index page with search, filters and A–Z navigation.
- **Tabbed mega menu** (Menu & mega menu → type "Tabbed"). It has categories on the left, links and site search in the middle, and technology logos with an illustration on the right. Header CTA: "LET'S TALK" pill.
- **Programmatic SEO:** 6 master templates, all built from the same design sections: SEO by city, SEO by industry, Hire {technology} developers, {technology} development company, Web design for {industry}, Website development by city. Linked pages follow the template automatically.
- **Integrations & APIs:** email (Web3Forms, EmailJS, Formspree, custom), auto-reply, webhooks, Slack, Discord, Telegram, HubSpot, GA4, GTM, Meta Pixel, Clarity, LinkedIn, Search Console/Bing verification, WhatsApp button, cookie banner, AI writing assistant (Anthropic or OpenAI key).
- **SEO tools:** image alt-text audit, broken-link checker, scheduled publishing, revisions, authors, backup and restore.
- **Export & backup → Export the website** downloads a static site (.zip) that you can upload to any host. It includes sitemap.xml, robots.txt, llms.txt, redirects, schema and working forms.
